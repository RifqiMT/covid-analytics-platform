# User Persona — Product Analyst

## Summary
- **Name**: Product Analyst “Alya”
- **Goal**: Compare country trends (cases/deaths/recovery) to support product narratives and market planning.
- **Primary workflows**: Select a focus set of countries, switch granularity, inspect charts and table for latest bucket.

## Context
- Comfortable with dashboards and basic analytics
- Needs fast comparisons without manual data wrangling

## Pain points
- Datasets are inconsistent (recovered, missing days)
- “All countries” views can be slow or overwhelming
- Needs clarity on what “as-of today” means when sources lag

## Needs & expectations
- Fast and stable UI
- Clear metric names and formulas
- Transparent notes (data-through date, mirroring behavior)

## Acceptance criteria
- Can quickly select 5–10 countries and compare trends
- Tooltip provides sorted values (largest first)
- Table supports search and “All rows”
